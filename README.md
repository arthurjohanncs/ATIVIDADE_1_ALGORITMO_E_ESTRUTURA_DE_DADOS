# ATIVIDADE_1_ALGORITMO_E_ESTRUTURA_DE_DADOS
Discentes: Arthur Johann Costa Silva e Albert Nonato Costa Albuquerque
Um programa básico desenvolvido em linguagem C para gerenciar uma lista de notas utilizando CRUD (Create, Read, Update, Delete).

O programa exibe um menu interativo com as seguintes opções:
=> Inserir nota (Create): Adiciona uma nova nota ao vetor (capacidade máxima de 100 elementos).
=> Listar notas (Read): Exibe todas as notas cadastradas junto com suas respectivas posições.
=> Atualizar nota (Update): Modifica o valor de uma nota existente a partir de sua posição.
=> Deletar nota (Delete): Remove uma nota da lista pelo índice e reorganiza o vetor.
=> Sair: Encerra a execução do programa.
